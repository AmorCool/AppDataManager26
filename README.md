# AppData Manager

**مدير بيانات التطبيقات لنظام iOS**

أداة احترافية لإدارة بيانات التطبيقات على أجهزة iOS العاملة ضمن بيئة Jailbreak.

يوفر AppData Manager مجموعة متكاملة من الأدوات لاستعراض بيانات التطبيقات، معرفة أحجامها، إنشاء النسخ الاحتياطية واستعادتها، وإزالة بيانات التطبيقات عند الحاجة، مع توفير حماية للبيانات والتطبيقات الحساسة للنظام.

**المطور:** ZAIN (@Zainqkvd)

---

## المميزات

### إدارة التطبيقات
- عرض التطبيقات المثبتة على الجهاز مع معلوماتها الأساسية (الاسم، Bundle ID، حجم البيانات)
- حساب حجم البيانات بشكل دقيق وشامل

### حذف بيانات التطبيق
- إزالة بيانات التطبيق بشكل آمن (Documents, Library, Caches)
- حماية تطبيقات النظام من الحذف العرضي

### النسخ الاحتياطي والاستعادة
- إنشاء نسخة احتياطية شاملة من بيانات التطبيق
- استعادة البيانات من النسخ الاحتياطية
- إدارة النسخ الاحتياطية (حذف، استعراض)

### البحث
- البحث السريع عن التطبيقات بالاسم أو Bundle ID

### الواجهة
- واجهة داكنة احترافية
- دعم كامل للغة العربية
